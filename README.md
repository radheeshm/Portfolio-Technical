# Radheesh M — Technical Portfolio Website

## Files
- `index.html` — page content and structure
- `styles.css` — responsive green theme and layout
- `script.js` — mobile navigation and footer year

## Preview locally
Open `index.html` in a modern browser. The site uses only static HTML, CSS and JavaScript.

## Publish to the existing GitHub Pages repository
1. Download and extract this ZIP.
2. Review `index.html` and update any content you want to change.
3. Back up your current portfolio repository before replacing files.
4. Copy `index.html`, `styles.css`, and `script.js` into the publishing source folder of your existing `portfolio` repository.
5. Commit and push the changes to the branch/folder configured for GitHub Pages.
6. Check the Pages deployment status in the repository's **Settings → Pages**.

GitHub Pages can publish static files from a selected branch and folder. The site is not uploaded or published by this package. Do not put private information in a public Pages repository.

Official guide: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Before publishing
- Confirm that the phone number and email address are still the preferred public contact details.
- Check all dates and project descriptions.
- Add project screenshots or demo links only where you have a public, working example.
- Keep project status accurate; the BrandForge-AI description intentionally says selected modules were developed and does not claim all planned modules are complete.
